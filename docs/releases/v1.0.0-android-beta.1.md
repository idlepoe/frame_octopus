# Frame Octopus 1.0.0 — Android beta 1

The Android app now follows **Select → Creating → Complete**. Starting a job replaces the editor with a dedicated progress screen; finished results appear automatically with save-selected and new-collection actions.

## Download

- `Frame-Octopus-1.0.0-Android-arm64-v8a.apk`: release-signed APK for ARM64 Android 7.0/API 24 or newer.
- App version: 1.0.0; ARM64 split APK version code: 2004 (base Flutter build number 4).
- `SHA256SUMS.txt`: asset integrity checksums.
- `Third-party-notices-Android.zip`: application/package notices and native build/source references.

The APK is signed with the release certificate. A differently signed development APK cannot be updated in place. Export wanted results before removing a development installation; its private settings/cache are removed with it. Original videos and files already exported to the gallery are separate.

## Included

- Fluent UI controls, the octopus mascot and English/Korean/Japanese interfaces.
- Gallery multi-selection, video preview, still PNG and animated WebP contact sheets.
- 20 MB per-file default, automatic scene count, clip duration and source-aware FPS.
- Original scene ratio and flexible layouts, with manual overrides in Advanced.
- Dedicated loading screen with percentage, current file and a persistent Stop action.
- Result-only completion view, selected saving/sharing/deletion and new-batch reset.
- Distinct cancellation/failure states instead of reporting every finished attempt as success.
- Firebase Core project connection with automatic data collection disabled; no Analytics or media-upload feature.
- Hosted privacy policy: [English](https://frame-octopus.web.app/privacy), [한국어](https://frame-octopus.web.app/ko/privacy), [日本語](https://frame-octopus.web.app/ja/privacy).

## Validation and current limits

Static analysis and 19 Flutter tests passed. The development build was checked on Samsung SM-A346N (Android 16) for selection, real PNG/WebP generation, gallery saving, sharing, processing/completion transitions and cancellation. The release APK's manifest, ARM64 contents and APK v2 signature were verified. The signed release was not installed over the differently signed development app.

Creation currently runs while the app stays open. Leaving the app cancels unfinished work. Android's default maximum width is 1280 px; Advanced offers 960/1280/1920 px. Animated sheets play representative scenes simultaneously without audio; they are not full-timeline video exports.

This prerelease contains an Android APK. It does not publish to Google Play, replace the Microsoft Store submission, or include an iOS build. The repository includes an iOS development handoff guide for future work.

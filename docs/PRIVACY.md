# Privacy policy

Frame Octopus processes selected videos locally on your Windows PC. The app does not upload videos, collect analytics, show advertisements or require an account.

The app stores interface preferences and language in local application preferences. Imported videos are read from the paths you choose; they are not modified. Preview thumbnails and temporary encoding data are stored in temporary application folders. Completed images are stored in application support storage and copied to a folder only when you choose Save. Export never deliberately overwrites an existing file.

Failed capacity attempts are deleted automatically. Successful results remain in application support storage so they can be previewed and exported. To remove that local data, close the app and delete its Frame Octopus application support folder. Copies exported to another folder are managed separately by you. Windows file dialogs and Windows itself may retain their normal recent-file records.

No network permission is requested for media processing. Development dependency downloads happen during build, not during video conversion.
